# The request set for spec 02. Each line is "METHOD path"; # starts a comment.
# The recording workflow sends every line to the old app (twice) and stores what comes back.
# Each group names the old-app source it was read from. Paths are relative to
# NuGetGallery at 63e6ee4202b441e1c904d6f78fc7b070f36bc24f, src/NuGetGallery/:
#   App_Start/Routes.cs                            routes v2PackageIds and v2PackageVersions; no HTTP method constraint
#   Controllers/ApiController.cs                   GetPackageIds / GetPackageVersions: [HttpGet], bind partialId|id,
#                                                  bool? includePrerelease, bool? testData, string semVerLevel; JsonResult
#   Queries/AutocompleteDatabasePackageIdsQuery.cs  Available+Listed, SemVer filter, prerelease filter; StartsWith,
#                                                  GroupBy Id, OrderBy Id, Take 30; blank partialId -> top 30 by DownloadCount
#   Queries/AutocompleteDatabasePackageVersionsQuery.cs  Id == id, same filters, no ORDER BY; blank id -> exception
#   ../NuGetGallery.Core/SemVerLevelKey.cs          semVerLevel parsed with NuGetVersion.TryParse; >= 2.0.0 means SemVer2
#   Web.config                                     httpRuntime requestPathInvalidCharacters, relaxedUrlToFileSystemMapping
#
# "<c*N>" in a line stands for the character c repeated N times (scripts/runner/common.ps1, Expand-RequestLine),
# so the very long requests below stay readable. Record names use the line as written.
#
# Not sent, on purpose:
# - a path that matches neither route, such as /api/v2/package-versions/Serilog/extra, or a dot segment that resolves to
#   one (/api/v2/package-versions/..). It never reaches these two endpoints, so it is not the new service's to answer;
#   the proxy in the next spec sends it to the old app.
# - query values that ASP.NET request validation rejects (partialId=%3Cx, partialId=%26%23x, semVerLevel=%3Cx). The old
#   app answers 500, and its own code writes the body: ApiController.OnException sends the exception's stack trace to a
#   local client and its message to a remote one (exploratory record run 44674677772). Neither amendment A1 nor A4
#   covers an app-written body, so these wait for a decision; see evidence/02/reviews.md, finding A2.
